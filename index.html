ÉTAPE 1
Va sur console.firebase.google.com, connecte-toi avec un compte Google, et clique Créer un projet.
ÉTAPE 2
Active Realtime Database → Créer une base → choisir région Europe (europe-west1) → Mode test (30 jours, assez pour jouer !).
ÉTAPE 3
Dans Paramètres du projet → Vos applications → ajoute une app Web </>. Copie l'objet firebaseConfig.
